### 10.2 Чего QA **не** покрывает
- Баланс как таковой (нет тестов «уровень за N часов») — только `npm run balance:sim` как модель.
- Нагрузку (concurrency 100+ игроков на одном `players.id`).
- Реальный Telegram-вебхук (нужен живой токен), оплату Stars end-to-end.
- Визуальную регрессию (скриншоты/пиксельные диффы).
- Мобильный Safari/старые WebView.
