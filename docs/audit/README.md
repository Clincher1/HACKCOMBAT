# Аудит HACKER KOMBAT (v5.1)

Пакет документов для внешнего разбора: всё о игре — баланс, механики, контент, API, база, UX, риски.

| Файл | Размер | Что внутри |
|---|---|---|
| **`HACKER-KOMBAT-AUDIT.md`** | ~122 КБ, 1 120 строк | Основной документ: паспорт, петля, архитектура, формулы, все справочники (30 миссий, 48 карточек, 10 апгрейдов, 8 NPC, 3 питомца, 28 скинов, 18 рамок, 8 локаций, 3 темы, 80 достижений, 6 инцидентов, сезон), прогрессия и симуляция, API, клиент, БД, QA, 20 находок (F1–F20), бэклог |
| `raw-config.json` | ~147 КБ | Машинный дамп всех конфигов из `shared/*.config.ts` — для парсинга и сравнений |
| `qa-results.md` | 4 КБ | Снимок прогона `npm run qa:all` (521 проверка, 0 падений) |

## Как отдать другому ИИ

Скопируй `HACKER-KOMBAT-AUDIT.md` целиком (или приложи файлы) и добавь запрос, например:

> Ты — геймдизайнер и баланс-аналитик idle/clicker-игр. Ниже — полный аудит Telegram Mini App «HACKER KOMBAT»: формулы, контент, экономика, симуляция прогрессии, находки F1–F20. Разбери:
> 1) где экономика ломается и почему (особенно находка F1 про пассив 1,32 млрд Data/час);
> 2) достижим ли первый престиж и как сократить путь до него без инфляции;
> 3) какие 5 изменений дадут максимальный рост удержания D1/D7;
> 4) что противоречит заявленному тону «чилово, без киберпанка и фантастики».

## Как воспроизвести цифры

```bash
npm install
npm run balance:sim   # модель 60 суток
npm run qa:all        # 20 сьютов (~50 с)
npm run build         # tsc + vite + единая serverless-функция
```

Дамп конфигов пересобирается импортом `shared/*` (см. §13.1 основного документа).
