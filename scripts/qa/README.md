# QA-скрипты (v3.3)

Живые проверки против локального dev-сервера. Ничего не пишут в прод.

```bash
npm install
npm run dev            # терминал №1 — сервер на :5173

node scripts/qa/api.mjs          # ~2 мин: полный API (миссии, гейты, экономика, античит)
node scripts/qa/clicks.mjs       # ~1 мин: быстрый тап не ловит 429; флуд режется античитом
npm run qa:integrity              # finite XP/Data, prestige cap, migration/RPC и MAX UI checks
npm run qa:offline                # мгновенно: оффлайн-экономика v3.2 (собирает и грузит api/_core.cjs)
npm run qa:buy                   # ~30 с: покупки с «хвостом» кликов (v3.3), без dev-сервера
```

## Оффлайн-копилка v3.2 (`npm run qa:offline`)

Скрипт не требует ни dev-сервера, ни Supabase: он подгружает собранное ядро
`api/_core.cjs`, уводит `memory-fallback` в временный каталог и **сам двигает время**
через `Date.now`. Поэтому «3 часа оффлайна» проходят за миллисекунды.

Что проверяется:

- 8 минут (480 с) реальной игры за сутки — обязательное условие копилки;
- недобранные сутки не платят ничего и не создают «долг впрок»;
- пауза > 45 с не считается игрой;
- ставка тапов 0.1/сек × сила клика, карточки в оффлайне — ×0.5, кап 8 часов;
- оффлайн даёт только Data (ни XP, ни Crypto, ни чипов);
- смена суток по Москве (UTC+3) обнуляет счётчик; часы после полуночи не оплачиваются
  до новой 8-минутной сессии;
- старым сейвам (играли до v3.2) поблажка выдаётся **ровно один раз** — проверяется
  отдельным процессом `legacy-grace-child.cjs` с подготовленным `.local-db.json`.

## Быстрые покупки (`npm run qa:buy`)

Проверяет, что покупка не улетает на сервер с устаревшим балансом:

- клики, ещё не отправленные на сервер, едут вместе с покупкой (`clicks` в теле запроса);
- сервер применяет их **до** проверки цены и возвращает `appliedClicks`;
- античит режет «хвост» (максимум 20 кликов на покупку, 60 на `/api/click`) и честно
  сообщает, сколько зачёл, чтобы клиент дослал остаток;
- неудачная покупка не съедает клики и не начисляет их дважды.

## Другие проверки

```bash
npm run balance:sim              # finite simulator: entry/Energy/offline/offers/chips/prestige
./node_modules/.bin/tsc -b       # типы
npm run build                    # прод-сборка + бандл API
```

## Правила

- Каждый скрипт создаёт **изолированных гостей** (`x-demo-user-id`), прод-игроков не трогает.
- Тесты не должны падать от достижений: любые «лишние» начисления — это бонусы, а не баг.
- Все проверки читают реальные конфиги из `shared/*`, поэтому балансные правки
  автоматически отражаются в тестах.
